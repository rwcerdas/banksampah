# EcoBank Admin Guide

## Admin Panel (`/admin`)

| Menu | Fungsi |
|------|--------|
| Dashboard | Statistik operasional, grafik tren |
| Nasabah | CRUD nasabah individual & kelompok |
| Transaksi | Penimbangan / setor sampah |
| Penarikan | Approve/reject permintaan penarikan nasabah |
| Riwayat | Log semua transaksi |
| Laporan | Laporan penimbangan, DLH, AI insight |
| Kategori & Harga | Master harga sampah + export PDF/Excel |
| Pengepul | Data pengepul & harga per item |
| Edukasi | Artikel edukasi untuk nasabah |
| Kas Pengurus | Pencatatan kas operasional |
| Pengaturan | Nama BS, logo, markup % |

## Nasabah Mobile (`/nasabah`)

- Beranda: saldo, kartu member, quick actions
- Tracker: mutasi, transfer, penarikan, analisis
- Harga: daftar harga sampah (after markup)
- Edukasi: artikel dari admin
- Profil: data rekening, ganti password

## Tips Operasional

1. Set markup di Pengaturan sebelum operasional
2. Daftarkan nasabah dengan login untuk akses portal HP
3. Nasabah wajib ganti password saat first login
4. Gunakan PWA install di HP nasabah untuk pengalaman app-like
